## Creación de switch para problemas y ejercicios

En lugar de usar una sentencia switch usaremos un array de funciones.

La idea consiste en aprovechar el índice de función para como selector

**Pregunta de investigación:** ¿Se puede crear un array de funciones?

==Resultados de investigación ↓↓↓↓↓==
### 1. Misma Firma Obligatoria

- [x] Todas las funciones del array deben tener la **misma firma**.
	- Esto significa: mismo **tipo de retorno** y mismos **tipos de parámetros**.
	- No se puede mezclar una función que recibe `int` con una que recibe `float`.
### 2. La Sintaxis del Puntero a Función

- [ ] La sintaxis para declarar un puntero a función.
	- Se lee de adentro hacia afuera usando paréntesis para romper la precedencia.
	- `int (*mi_puntero)(int, int);` descodifica como: un puntero llamado `mi_puntero` a una función que recibe dos `int` y devuelve un `int`.
	
>[!WARNING]
> - Crear el array directamente con la sintaxis nativa es confuso y propenso a errores.
### 3. El uso de `typedef` o `using` (Altamente Recomendado)

- [ ] Crear un **alias de tipo** primero.
	- Esto significa: convertir la firma de la función en un nuevo "tipo de dato" que puedes usar para el array.

>[!IMPORTAND]
> Garantía de ingreso en rango de array de funcion
